# CHERUKURU INNDHU SREE — Portfolio

A responsive, dark-premium personal portfolio highlighting Data Science, AI, full-stack development, internships, projects, credentials, programmes, technology events, and classroom knowledge-sharing.

## Preview locally

Open `index.html` in a modern browser. Keep the `assets` folder beside it; it contains the portrait, résumé PDF, and event/presentation photos used by the site.

## Publish with GitHub Pages

1. Create a public repository named `<your-github-username>.github.io` (or use an existing repository configured for Pages).
2. Upload the contents of this folder to the repository root. `index.html` must be at the root and `assets/` must remain alongside it.
3. For a project repository, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the deployment to finish and open the URL shown in Settings → Pages.

## Before sharing with recruiters

- Add direct repository URLs to the individual project cards when those repositories are public. Current project links lead to the GitHub profile rather than specific repositories because exact repository URLs were not supplied.
- Add credential verification URLs if available.
- Review contact details and test the résumé download after publishing.
